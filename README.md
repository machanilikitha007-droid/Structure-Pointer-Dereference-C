# Structure Pointer Dereference in C

**Author:** M.Likitha

## Description

This program demonstrates the use of the dereference operator with a pointer to a structure.

The expression `(*ptr).member` is used to access structure members through the pointer.

## Concepts Used

- Structures
- Structure pointers
- Dereference operator `*`
- Structure member access
